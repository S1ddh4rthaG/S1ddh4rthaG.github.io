# Dhwani Sarathi

## Smart India Hackathon (SiH) 1403: App-Based Audiometer

Dhwani Sarathi is a revolutionary mobile application designed to transform how hearing loss is detected and monitored in school children. The project was developed as part of the Smart India Hackathon to address the need for a portable, efficient, and user-friendly audiometry solution.

{% include elements/figure.html image="https://raw.githubusercontent.com/S1ddh4rthaG/DhwaniSarathi/main/Screenshots/winners.jpeg" caption="SIH Team GPS4 - Techno India NJR Institute of Technology, Udaipur" %}

## Problem Statement
{:.mt-5}

Traditional Pure Tone Audiometers used for hearing loss detection are bulky instruments that require significant time for testing. This creates challenges in conducting large-scale hearing tests, particularly in school settings. The need was identified for a hand-held, mobile phone-operated audiometer that could streamline the testing process while maintaining accuracy.

Dhwani Sarathi provides a comprehensive solution with the following key features:

- **Pure Tone Audiometry Test**: Conducts professional-grade hearing tests using mobile devices
- **Results Analysis & Interpretation**: Provides detailed analysis and interpretation of test results
- **Classroom Management System**: Enables educators to manage and track student hearing health
- **Doctor Connectivity**: Helps users connect with nearby hearing specialists
- **Document Digitization**: Converts physical audiometry documents into digital format
- **Preliminary Checks**: Ensures optimal testing conditions through environmental and device checks

## Technical Implementation
{:.mt-5}

### Frontend (React Native)
- Built using React Native for cross-platform compatibility
- Implemented pure tone generation and analysis
- User-friendly interface with step-by-step test guidance
- Real-time data visualization for test results

### Backend (Django)
- RESTful API implementation for data management
- Secure user authentication and authorization
- Data analytics and reporting system
- Integration with external services

### Additional Technologies
- Firebase for user management and real-time data sync
- Machine learning models for audiogram digitization
- Google Maps integration for doctor location services
